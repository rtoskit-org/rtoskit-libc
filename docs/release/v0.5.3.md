rtoskit-libc 0.5.3 is the first release from the repository's new home, the `rtoskit-org` organisation. The library's code, headers and ABI are the same as in 0.5.2.

## Changed

- **The repository moved** from `sgstreet/rtoskit-libc` to `rtoskit-org/rtoskit-libc`, and the toolchain from `sgstreet/rtoskit-gcc` to `rtoskit-org/rtoskit-gcc`. GitHub redirects the old URLs, but update clones and scripts to the new ones (`git remote set-url origin https://github.com/rtoskit-org/rtoskit-libc.git`).

## Downloads

As for 0.5.0: one archive per architecture, `rtoskit-libc-0.5.3-<arch>.tar.xz`, holding the `release` and `speed` builds' headers and archives, with `SHA256SUMS` and a build-provenance attestation for each. The attestations now name the new repository:

```sh
gh attestation verify rtoskit-libc-0.5.3-armv7e-m.tar.xz --repo rtoskit-org/rtoskit-libc
```

Archives of 0.5.0 to 0.5.2 were attested before the move; verify them with `--repo sgstreet/rtoskit-libc`.

Nothing has to be rebuilt against 0.5.3. The 0.5.0 notes describe the library, its architectures and how to use it.
